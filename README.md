# Real Estate Database Management System

## Overview

This project is a Java Swing-based Real Estate Database Management System connected to a MySQL database.

The application provides separate interfaces for:

- Database Administrator
- Real Estate Office
- Real Estate Agents

The system supports:
- Property management
- Sales tracking
- Rental tracking
- Agent performance reports
- SQL query execution
- Role-based login system

---

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- Git
- GitHub

---

## Features

### Database Administrator Interface

The administrator panel supports:

- Houses built after 2023
- Houses within price ranges
- Rental filtering
- Top performing agents
- Agent performance analytics
- Most expensive properties
- Custom SQL query execution

---

### Real Estate Office Interface

Office users can:

- View sales reports
- View rental reports
- Filter properties
- Monitor agent performance
- Access property statistics

---

### Agent Interface

Agents can:

- Record property sales
- Record rental transactions
- View personal transactions
- Manage client-property interactions
